BARGE · DATA MODULE EDITOR

Load editable sound data into a built-in Barge renderer over USB-MIDI SysEx.

1 · Connect to Barge

Web MIDI SysEx permission is required. Connect to the running Barge firmware, not its updater. The WAVE renderer must be included in that firmware build.

Disconnected.

2 · Edit the WAVE data module

This test module is 32 unsigned 7-bit samples interpreted by Barge's already-linked wavetable instrument. It is data, not plug-in code.

3 · Send data to the instrument

No device reply yet.

The firmware validates the frame/checksum, queues a block-boundary table update, selects WAVE, and saves the data with settings once audio is quiet. Power-off persistence uses the normal Barge settings record.

This does not install executable modules or modify firmware code. Native run-time code loading is not implemented.

4 · Runtime Analog / Phase presets

Preset banks are external JSON data, not compiled into the firmware. Loading one updates parameters, modulation, and shared ADSR settings on the built-in renderer.

Choose a data preset.

BTN_ENV edits Attack / Decay / Sustain / Release. BTN_EDIT cycles the existing engine controls and added modulation pages.
